# 我的投資助手（iPhone 可安裝的免費網頁 App）

台股、美股、加密貨幣的持股管理＋技術分析。**資料只存在你的手機**，不需要註冊、不需要金鑰、不會用到有額度限制的服務。

## 一次性設定（約 10 分鐘，全程免費）

1. 登入 GitHub，右上角 **＋ → New repository**
   - 名稱隨意（例如 `invest`），**一定要選 Public（公開）**，按 Create。
2. 在新專案頁面點 **uploading an existing file**，把這個資料夾**裡面的全部檔案和資料夾**拖進去（包含 `.github` 資料夾），最下方按 **Commit changes**。
   - 如果 `.github` 沒被拖進去：按 Add file → Create new file，檔名輸入 `.github/workflows/pages.yml`，把同名檔案的內容貼上去存檔。
3. 到 **Settings → Pages**，**Source** 選 **GitHub Actions**。
4. 到 **Actions** 分頁，點左邊「部署與更新行情」→ 右邊 **Run workflow** → 綠色按鈕。等 1～2 分鐘變成綠色勾勾。
5. 回到 **Settings → Pages**，上方會出現你的網址（`https://你的帳號.github.io/專案名稱/`）。
6. **iPhone 用 Safari** 開這個網址 → 點下方「分享」→ **加入主畫面**。

之後從主畫面圖示開啟，就像一般 App。

## 行情從哪裡來

| 市場 | 來源 | 更新方式 |
|---|---|---|
| 加密貨幣 | Binance 公開行情 | App 開著時每 30 秒，**即時** |
| 台股、美股 | GitHub 定時抓取後存成檔案 | 盤中約每 15～20 分鐘，**延遲報價** |

畫面上每個價格都會標示「即時／延遲／手動」。延遲報價可能晚於實際行情數分鐘到數十分鐘，**不要拿來當下單依據**。

## 重要提醒

- **備份**：iPhone 若很久沒開，Safari 可能清掉網頁資料。請定期到「個人設定」→ 匯出備份，存到「檔案」。
- **持有清單外的台股／美股**：到「個人設定」複製「自動更新的標的清單」，貼到專案的 `data/watchlist.json`，這檔才會有自動報價。沒加也能用，只是要手動輸入現價。
- **排程可能被 GitHub 停用**：公開專案長時間沒動靜，GitHub 可能停用定時排程（我加了每月自動留紀錄來降低機率，但不保證）。若 App 提示「行情已多天沒更新」，到 Actions 分頁，看到黃色提示按 **Enable workflow** 即可。
- **「分析解讀」不是 AI**：它是依固定規則（均線、RSI、MACD）產生的文字，不會預測，也不是投資建議。
- 行情來源是沒有官方保證的公開服務，未來可能改版或失效，屆時行情需要調整；資料與持股計算不受影響。
